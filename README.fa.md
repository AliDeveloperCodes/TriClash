# TriClash 🪨📄✂️

یک بازی ساده و سرگرم‌کننه‌ی **سنگ‌کاغذقیچی** برای خط‌فرمان که با پایتون نوشته شده. حرکتت رو انتخاب کن، کامپیوتر رو به چالش بکش و ببین کی برنده می‌شه!

> این فایل رو به زبان‌های دیگه بخون: [English](README.en.md) · [Deutsch](README.de.md)

## امکانات

- رابط خط‌فرمان ساده و تمیز
- بازی در برابر حریف کامپیوتری با انتخاب تصادفی
- اعتبارسنجی ورودی (با ورودی نامعتبر کرش نمی‌کنه)
- شروع خودکار دوباره‌ی دور در صورت مساوی شدن
- امکان بازی دوباره بعد از هر دور

## نحوه‌ی کار

۱. یک منوی شماره‌دار نمایش داده می‌شه: `۱. سنگ`، `۲. کاغذ`، `۳. قیچی`
۲. عدد انتخابت رو وارد کن
۳. کامپیوتر به صورت تصادفی انتخاب می‌کنه
۴. برنده بر اساس قوانین کلاسیک سنگ‌کاغذقیچی اعلام می‌شه
۵. در صورت مساوی شدن، بازی به‌طور خودکار دوباره شروع می‌شه
۶. بعد از برد یا باخت، ازت پرسیده می‌شه که آیا می‌خوای دوباره بازی کنی یا نه

## پیش‌نیازها

- پایتون نسخه‌ی ۳ (بدون هیچ وابستگی خارجی)

## نصب و اجرا

ریپازیتوری رو کلون کن:

```bash
git clone https://github.com/<your-username>/TriClash.git
cd TriClash
```

بازی رو اجرا کن:

```bash
python game.py
```

### ویندوز

می‌تونی روی فایل `run.bat` هم دوبار کلیک کنی تا بازی اجرا بشه.
